# Botpanelim.com - E-Ticaret & WhatsApp Yönlendirme Projesi

Bu proje, kodlama eğitimi sürecimde e-ticaret mantığını kavrayabilmek ve kullanıcı deneyimini test etmek amacıyla geliştirdiğim bir çalışmadır.

### Proje Mantığı ve Akışı:
- Kullanıcı siteye girer ve kendisine uygun paketleri inceler.
- Gelişmiş API entegrasyon maliyetlerini minimumda tutmak ve müşteriyle doğrudan/hızlı iletişim kurabilmek adına **WhatsApp Web API yönlendirmesi** tercih edilmiştir.
- Kullanıcı "Satın Al" butonuna tıkladığında, arka planda dinamik bir link oluşturularak kullanıcının seçtiği paket bilgisiyle birlikte doğrudan WhatsApp sohbet penceresine yönlendirilmesi sağlanmıştır.

### Kazanımları:
- Front-End tasarımı ve kullanıcı arayüzü yönetimi.
- Dönüşüm odaklı (Conversion-oriented) minimum ürün (MVP) geliştirme deneyimi.
